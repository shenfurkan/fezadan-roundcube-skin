# Mail skin

Runtime files for the Roundcube 1.7.4 Elastic child skin. Copy this directory to
`roundcube/skins/fezadan` and set `$config['skin'] = 'fezadan';`.

Branding, optional plugins and licensing are documented in the repository root:
[`../README.md`](../README.md), [`../docs/BRANDING.md`](../docs/BRANDING.md),
[`../docs/OPTIONAL-PLUGINS.md`](../docs/OPTIONAL-PLUGINS.md).

`material.js` is generated by `npm run build`; do not edit it by hand.
